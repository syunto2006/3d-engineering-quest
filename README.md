# 3D Engineering Quest

10章・80ドリル。CAD以外が初めての人がSTL組立ビューアを作る開発キットです。

第1〜8章: 設計、HTML/CSS、状態、3D、STL、部品UI、手順、保存。
第9章: 閲覧モード、手順表示、分解、部品説明、視点、前後移動。
第10章: ミッション表、時間、姿勢、遠隔操作、ゴール判定、自動送り、保存。

参考の操作基準: https://ysntera.github.io/cansat-assembly-viewer/
学習サイト: https://syunto2006.github.io/3d-engineering-quest/

自分のプロジェクトは各課題の合格コードを引き継ぎます。app.js/experience.jsは関数と画面をつなぐ同梱コードで、すべて編集・持ち出し可能です。第9章以降ではpresentation.js/mission.jsに書いた関数が実行プレビューから呼ばれます。以前の64課題版の進捗は保持します。

AI/APIは使いません。3段階ヒント・理解チェック・実行テストを使います。Three.jsをCDNから取得するためネット接続が必要です。

ミッションは模式シミュレーションです。実機CanSatの物理・誘導センサー処理を保証しません。
