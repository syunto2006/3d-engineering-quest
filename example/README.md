# 自分のSTL組立ビューア

64ドリルで機能を積み上げるプロジェクトです。app.jsは機能をつなぐ同梱コードです。

## 起動
ネット接続のある新しいブラウザでGitHub PagesかローカルHTTPサーバーを使います。
Pythonがあれば python -m http.server 8000 を実行し http://localhost:8000 を開きます。

## 保存
完成したアプリからプロジェクトJSONを保存すると、STLと編集設定を一緒に保存できます。ブラウザ保存は端末間で同期しません。

## 公開
ファイルをGitHubリポジトリのルートへ置き、Pagesでmain / (root)を公開します。

## 制約
Three.js 0.170.0をCDNから取得します。STLには単位・正しい組立順は通常ないので、利用者が位置と順番を調整します。1ファイル20MB、合計30部品までです。
